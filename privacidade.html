Política de Privacidade

Esta Política de Privacidade explica como o Luxury Residences ("nós", "o hotel", "o aplicativo") recolhe, usa e protege os dados pessoais de quem se hospeda ou cria uma conta ("você", "hóspede"). Operado a partir de Luanda, Angola, contactável através de luxuryresidencesoffice@gmail.com.

Ao criar uma conta, você concorda com a recolha e o uso dos dados descritos abaixo.

1. Que dados recolhemos

  • Dados de conta: nome completo, email, senha (encriptada), telefone, data de nascimento, país.
  • Dados de reserva: quarto escolhido, datas de check-in/check-out, valor, e o nome/email/telefone informados no momento da reserva (podem ser diferentes dos dados da conta, caso reserve para terceiros).
  • Avaliações: nota e comentário deixados sobre uma estadia.
  • Solicitações de serviço: pedidos de spa, jantar, transfer, lavandaria, café da manhã ou concierge, com data/hora preferida e observações.

2. Para que usamos os seus dados

  • Criar e manter a sua conta de hóspede;
  • Processar reservas e solicitações de serviço junto à equipa do hotel;
  • Autenticar o seu acesso e proteger a conta contra uso indevido;
  • Enviar confirmações essenciais (cadastro, recuperação de senha).

Não vendemos os seus dados pessoais a terceiros.

3. Onde os dados ficam armazenados

Os dados são armazenados e processados através da infraestrutura da Supabase (banco de dados e autenticação), um fornecedor de serviços de nuvem de terceiros, com centros de dados localizados na União Europeia. Ao usar o Luxury Residences, você concorda com essa transferência.

4. Quem vê os seus dados

As suas reservas, avaliações e solicitações de serviço só ficam visíveis para você e para a equipa do hotel responsável pelo atendimento — nunca para outros hóspedes. Datas de ocupação de um quarto (sem nome, email ou qualquer dado pessoal) são usadas internamente apenas para evitar reservas duplicadas no mesmo período.

5. Partilha com terceiros

Partilhamos dados apenas com o prestador estritamente necessário para o funcionamento do serviço: a Supabase, para hospedagem de base de dados e autenticação.

6. Os seus direitos

  • Aceder ou corrigir os seus dados de perfil a qualquer momento, dentro do próprio aplicativo;
  • Solicitar a exportação ou eliminação da sua conta, contactando luxuryresidencesoffice@gmail.com;
  • Cancelar reservas ainda não concluídas diretamente no aplicativo.

7. Retenção de dados

Mantemos os seus dados enquanto a conta estiver ativa. Se solicitar o encerramento da conta, os dados são eliminados ou anonimizados dentro de um prazo razoável, exceto quando a retenção for exigida por lei (por exemplo, registos fiscais de reservas já concluídas).

8. Segurança

Aplicamos medidas técnicas razoáveis para proteger os seus dados, incluindo encriptação de senhas e controlo de acesso por linha (RLS), que garante que cada hóspede só acede às suas próprias reservas e dados.

9. Alterações a esta política

Esta política pode ser atualizada periodicamente. Alterações relevantes serão comunicadas dentro do próprio aplicativo ou por email.

10. Contacto

Para qualquer questão sobre esta política ou sobre os seus dados, contacte: luxuryresidencesoffice@gmail.com.
